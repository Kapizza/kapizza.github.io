# kapizza.github.io

Personal portfolio website for Daviti Gochitashvili, hosted on GitHub Pages.

## Structure

- `index.html` — single-page portfolio (bio, projects, publications, contact)
- `daviti-gochitashvili-resume.pdf` — downloadable resume
- `img/` — images used on the site

## Development

Open `index.html` directly in a browser or serve locally:

```bash
python3 -m http.server
```

The site is automatically deployed from the `main` branch via GitHub Pages.
